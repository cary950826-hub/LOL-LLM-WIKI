# 原始文獻 05：符文大地宇宙與 IP 全面擴張（奧術、衍生作與未來）

## 1. 宇宙重塑：從「召喚師」到「符文大地（Runeterra）」世界觀
早期《英雄聯盟》的故事背景較為簡陋：玩家扮演坐在終端機前的「召喚師（Summoner）」，召喚英雄於正義之地進行代理人戰爭以解決城邦衝突。
* **2014 年重大敘事重啟（Retcon）**：Riot 宣布全面移除「召喚師」與「正義之地」設定，將遊戲世界升級為一個充滿政治鬥爭、歷史神話與多元文明的龐大宇宙——「符文大地（Runeterra）」。
* **各大區域體系建立**：皮爾托福（科技進步之城）、佐恩（底層地下城）、諾克薩斯（鐵血擴張帝國）、蒂瑪西亞（崇尚榮譽但畏懼魔法）、弗雷爾卓德（冰原部落聯盟）、愛歐尼亞（靈性均衡仙島）、蘇瑞瑪（沙漠古代帝國）、巨石峰（星靈神話高山）以及闇影島（黑霧亡靈之地）。

## 2. 跨媒介顛峰之作：動畫影集《奧術》（Arcane）
由 Riot Games 攜手法國 Fortiche 製作公司耗時六年打磨的動畫影集《奧術》（Arcane），於 2021 年在 Netflix 上線：
* **卓越品質與口碑神話**：結合獨特的 2D 手繪筆觸與 3D CG 渲染風格，深入刻劃吉茵珂絲（Jinx）與菲艾（Vi）姊妹情仇，以及皮爾托福與佐恩階級矛盾。
* **影視成就**：在爛番茄拿下罕見的 100% 好評，奪下「黃金時段艾美獎（Primetime Emmy Awards）」最佳動畫節目獎，並橫掃安妮獎（Annie Awards）九大獎項，被公認是有史以來最成功的電玩改編影視作品。
* **第二季完結（2024 年底）**：為皮爾托福與佐恩雙城故事畫下壯烈句點，同時宣示 Riot 將展開符文大地其他區域（如諾克薩斯、愛歐尼亞）的影視宇宙拓展。

## 3. 衍生遊戲矩陣與多元品類覆蓋
為了擺脫「單一爆款遊戲」的風險，Riot 於十週年慶典（2019）一口氣公佈多款衍生作品矩陣：
* **《聯盟戰棋》（Teamfight Tactics, TFT）**：在自走棋狂潮中脫穎而出，成為全球最長壽且賽事規模最大的自走棋遊戲。
* **《符文大地傳說》（Legends of Runeterra, LoR）**：高品質數位集換式卡牌（CCG），深入補完符文大地的世界細節與歷史人物。
* **《英雄聯盟：激鬥峽谷》（Wild Rift）**：針對手機與家機平台量身重製，將平均對局時長壓縮至 15~18 分鐘，搶攻行動端電競版圖。
* **Riot Forge 發行計畫**：與獨立工作室合作推出單機冒險遊戲（如《聯盟外傳：殞落王者》、《聯盟外傳：聚合之力》）。

## 4. 未來展望：大型多人在線角色扮演遊戲（MMORPG）
Riot 官方證實正在研發一款以符文大地為舞台的大型多人在線遊戲（代號 Project F / LoL MMO）。雖然經歷重新定位與長期開發打磨，但其承載著全球數億玩家探索真實 Runeterra 大陸、親歷符文戰爭的終極願景，被視為 Riot 未來二十年的旗艦支柱。
